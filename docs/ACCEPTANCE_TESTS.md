# 驗收測試

## 核心

- 同一 `batchId` 重試不得扣款兩次。
- API 中斷後重開可從安全階段繼續。
- 無插件操作時仍可結束本輪並分析聊天。
- 確定交易不依賴 AI 成功。
- 切換聊天後資料完全隔離。
- Swipe 重抽不得重複提交。
- 回憶日期不得推進主時間線。

## 衣櫥與物品

- 明確獲贈衣物自動加入。
- 試穿不加入。
- 贈送／借用含糊時進待確認。
- 主聊天再次提及已購買物品不得重複增加。

## 活動、排名、評價

- 報名不等於參與或完成。
- 不符合資格不可報名。
- 未參加演武顯示未參賽／未入榜。
- 考核前不得生成考核排名。
- 評價必須有來源；技能數值上升不得自動生成稱讚。

## 書信與問答

- 草稿不屬於正式事件。
- 寄出後扣郵費並建立運送事件。
- 未到送達時間不可標記已送達。
- 問答助手內容不得進主聊天交接。

## 回滾

- 回滾購買恢復貨幣和庫存。
- 明確依賴可提示級聯撤銷。
- 可能相關不得自動刪除。
